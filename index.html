What is it worth?

Hover an item in Path of Exile 1 or Path of Exile 2, press a hotkey, and Looting Glass shows live listings from the official trade site and poe.ninja prices on top of the game. Native Rust and Qt: no Electron, no browser.

Install On console? Use your phone

KDE Plasma on Wayland is the tested platform. Windows and Hyprland are experimental.

Features

  • Any item

    Uniques by name, rares and magic items by their mods, plus gems, currency, fragments, divination cards and more.

  • Editable filters

    Every matched mod has a checkbox and min/max values, pre-filled from your roll minus a tolerance. The search re-runs as you edit.

  • poe.ninja prices

    Currency, fragments, essences, scarabs, runes, omens and other stackables, with the 7-day trend and the value of the whole stack.

  • Fair comparisons

    Armour, evasion, energy shield and physical DPS are compared at 20% quality, like the trade site. Weapons get DPS, attack speed and crit filters.

  • Both games, one app

    Switch game from the tray, the settings or a hotkey. Each game remembers its own league.

  • A proper overlay

    On the game's screen, always on top. Drag the ⠿ handle to move it, its edges to resize it, and pin it to keep it open.

  • Results at a glance

    Price, item level, listing age and seller, an online/any toggle, and one click to the full search on pathofexile.com.

  • Mod tiers

    With advanced item text (Ctrl+Alt+C) every mod shows its tier and roll range, like "T2 · 50–59", with top-tier rolls highlighted.

  • Bulk exchange

    Next to the poe.ninja average, the cheapest offers on the trade site's bulk exchange right now, with stock and the price per unit.

  • Map check PoE 1

    A separate hotkey lists a map's mods and colours the ones you marked as deadly or annoying, so you know before you run it.

  • Manual check

    Paste item text from a friend or a forum post into a native window and check it without the hotkey.

Install

The download buttons get the latest release. Checksums and older versions are on GitHub releases.

Linux

Needs KDE Plasma 6 on Wayland and Qt 6. On Arch / CachyOS, install the runtime libraries (already there on most Plasma desktops):

sudo pacman -S --needed qt6-declarative layer-shell-qt kirigami qqc2-desktop-style
Download for Linux

Then, in the folder you downloaded it to:

tar xzf lootingglass-*-x86_64.tar.gz
cd lootingglass-*-x86_64
./install.sh

The release binaries are built on Arch and need a Qt at least that new, so a rolling distro (Arch, CachyOS, EndeavourOS) is the safe bet. Elsewhere, build from source.

Arch Linux package

Until lootingglass-bin is on the AUR, build the same package from the repository. It installs through pacman with its dependencies, and pacman -R lootingglass-bin removes it.

git clone https://github.com/looting-glass/desktop.git looting-glass
cd looting-glass/packaging/aur/lootingglass-bin
makepkg -si

Windows experimental

Download installer Portable .zip

The installer sets it up for your user only (no admin rights), adds a Start menu entry, can start with Windows and uninstalls from Settings → Apps. For the portable version, extract the .zip anywhere and run lootingglass.exe.

The downloads aren't code-signed yet, so SmartScreen may warn you: click More info → Run anyway. Run the game in windowed fullscreen; Windows can't draw the overlay over exclusive fullscreen.

From source

Needs Rust (edition 2024), a C++ compiler and the Qt packages above, plus qt6-base.

sudo pacman -S --needed rustup qt6-base qt6-declarative \
    layer-shell-qt kirigami qqc2-desktop-style
git clone https://github.com/looting-glass/desktop.git looting-glass
cd looting-glass
./install.sh

install.sh installs to ~/.local/bin/lootingglass with a launcher entry and icon. Start Looting Glass from the application launcher; it lives in the system tray.

Usage

  1. In the game, hover an item and press Ctrl+D.
  2. The first time, KDE asks you to confirm the shortcuts and to let Looting Glass control the keyboard, so it can press Ctrl+C in the game. Both are remembered.
  3. Adjust the filters if you like. The search updates automatically.
  4. Press Esc or Space, or click back into the game, to close the overlay. To keep it open while you play, click the pin next to ✕: it then stays until you press ✕ or Esc.

Manual price check

Click the tray icon (or Manual check… in its menu), paste the item text and press Check price or Ctrl+Enter. The results open in the overlay as usual.

Map check PoE 1

Assign the Map check shortcut, hover a map and press it. The overlay lists the map's mods: click one to mark it annoying, again for deadly, and once more to clear it. Marks cover every roll of a mod, so the next map with a mod you can't run shows it in red right away. Settings → Maps lists the marks; Settings → Game turns the check off.

Hyprland experimental

Hyprland doesn't let apps choose their own keys, so bind them in hyprland.conf:

bind = CTRL, D, global, dev.lootingglass.LootingGlass:price-check
bind = , F7, global, dev.lootingglass.LootingGlass:toggle-game     # optional

The shortcut ids are price-check, toggle-game, settings, manual-check, hide-overlay, item-info and map-check. If a bind does nothing, hyprctl globalshortcuts shows the names your portal registered.

Settings

Click the tray icon to open the settings window, or edit ~/.config/lootingglass/config.toml (on Windows %APPDATA%\lootingglass\config.toml) by hand:

game = "poe1"            # or "poe2"
contact = ""             # optional, appended to the User-Agent sent to the trade API

[poe1]
league = "Standard"

[poe2]
league = "Standard"

[trade]
status = "online"        # "online", "any", or "securable" (PoE 2 instant buyout)
stat_tolerance = 10      # % below your roll used as the filter minimum
min_from_tier = false    # with Ctrl+Alt+C text: minimum = bottom of the mod's tier range
max_results = 20

[map_check]              # PoE 1 maps
enabled = true
deadly = ["Monsters reflect #% of Elemental Damage"]   # mod text, numbers as #
annoying = []

[overlay]
side = "right"
margin_top = 80
margin_side = 24
width = 380
max_height = 0           # 0 = fit content
pinned = false           # true = stay open when clicking the game

[shortcuts]              # Windows only; on Linux shortcuts belong to the desktop
price_check = "Ctrl+D"

Troubleshooting

The overlay has a title bar or isn't on top.
Looting Glass has to run as a native Wayland client. It overrides QT_QPA_PLATFORM=xcb for itself, but started with LOOTINGGLASS_ALLOW_X11=1 the overlay can't use layer-shell.
"The game didn't copy anything".
Make sure the cursor is over an item and that you allowed keyboard control when KDE asked. To reset that permission, delete ~/.local/state/lootingglass/remote-desktop.token and restart Looting Glass.
On Windows, the overlay doesn't show over the game.
Switch the game to windowed fullscreen (borderless). Exclusive fullscreen hides other windows.
I need debug output.
Run RUST_LOG=lootingglass=debug QT_FORCE_STDERR_LOGGING=1 lootingglass in a terminal, and open an issue with what it prints.
